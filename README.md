Notre application est basée sur es discours de présidents français.
Elle permet de :
 - Afficher la liste des mots les moins importants dans le corpus de documents.
 - Afficher le mots ayant le score Td-Idf le plus élevé.
 - Indiquer le mot le plus répété par le président Chirac.
 - Indiquer les noms des présidents ayant prononcé le mot 'Nation' et le nom de celui l'ayant le plus prononcé.
 - Indiquer le premier président à parler d'écologie et/ou de climat.
 - Indiquer le mot que tous les présidents ont prononcé.

Afin d'éxécuter notre code, il faut lancer le fichier chaque fois qu'une instruction est nécessaire.
Il faut ensuite suivre les instructions à l'écran.
